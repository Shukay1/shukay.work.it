# Ширин

Демонстрационная витрина кондитерской. В меню 16 позиций, включая торты, десерты, выпечку и наборы.

Откройте `index.html` в браузере. Изображения встроены в файл. Поиск, фильтры и корзина работают локально. Корзина сохраняется в браузере, а заказ можно скопировать.

Ассортимент и цены в сомах приведены для демонстрации.
